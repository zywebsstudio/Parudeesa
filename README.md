# PARUDEESA PLANTATION POOL VILLA — LUXURY RESORT WEBSITE

A luxury hospitality website designed and developed for **Parudeesa Plantation Pool Villa**, located in Vaduvanchal, Wayanad, Kerala, India.

## Tech Stack
- **Next.js 16 (App Router)**
- **React 19**
- **TypeScript 5**
- **Tailwind CSS v4**
- **GSAP & ScrollTrigger**
- **Lucide React Icons**
- **Lenis** (Smooth Luxury Scroll)

## Core Sections
1. **Header & Navigation**: Transparent-to-ivory sticky navigation with mobile drawer menu and instant WhatsApp booking CTA.
2. **Immersive Hero**: Automatic crossfade slider with subtle zoom effect, dual CTA, and GSAP text entrance.
3. **About the Resort**: Editorial asymmetrical layout highlighting the 4 private pool cottages, lush plantation setting, and personalized hospitality.
4. **Private Pool Cottages**: Showcase of the 4 private pool sanctuaries with direct WhatsApp enquiry compilation.
5. **Photo Gallery**: Asymmetrical masonry gallery with category filtering and interactive full-screen Lightbox.
6. **Experiences & Hospitality**: 4 signature highlights (Private Pool Experience, Plantation Living, Personalised Hospitality, Homemade Dining).
7. **Location & Attractions**: Interactive Google Maps embed for Vaduvanchal Wayanad, directions CTA, nearby highlights, and guest experience ethos.
8. **Booking & Contact**: Full-width plantation backdrop with Custom Stay Planner that compiles dates, cottage selection, and guests into a direct WhatsApp message.
9. **Footer**: Luxury 4-column layout with brand details, quick links, contact, and Zywebs developer attribution.
10. **Floating Socials**: WhatsApp & Instagram quick-access floating buttons with smooth back-to-top scroll.

## Configuration
All company details, phone numbers, WhatsApp message templates, and images are centralized in:
`data/siteData.ts`

## Getting Started
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the website.
